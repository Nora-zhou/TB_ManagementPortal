# Feature Specification: 1688采购订单供应商管理

**Feature Branch**: `006-supplier-management`

**Created**: 2026-05-26

**Status**: Ready for Planning

## Overview

基于 1688 导出的采购订单文件（`1688.xlsx`），为店主提供供应商维度的采购数据管理功能。用户上传 xlsx 文件后，可按月份筛选、以卖家公司名为维度查看每家供应商的订单数量与实付款合计，从而快速掌握采购结构和各供应商的往来金额。本功能基于现有 FastAPI + Vue 3 技术栈新增独立模块，不影响已有商品价格走势和订单分析功能。

## 1688 Excel 字段说明

1688 导出 xlsx 每行为一条**订单行**，文件结构如下：

- **主订单行**：`订单编号` 字段非空，包含完整订单信息（实付款、卖家公司名、订单状态、创建时间等）。
- **续行（多货品订单）**：当一个订单包含多个货品时，后续行的 `订单编号` 为空，仅包含货品标题、单价、数量等字段，`实付款(元)` 为空。

### 关键字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `订单编号` | string | 订单唯一 ID；续行为空 |
| `卖家公司名` | string | **供应商名称（聚合维度）** |
| `卖家会员名` | string | 供应商平台账号 |
| `货品总价(元)` | float | 商品标价合计 |
| `运费(元)` | float | 运费 |
| `涨价或折扣(元)` | float | 价格调整 |
| `实付款(元)` | float | **实际支付金额（核心统计字段）**；续行为空 |
| `订单状态` | string | 枚举，见下表 |
| `订单创建时间` | datetime | 下单时间（月份筛选依据） |
| `订单付款时间` | datetime | 付款时间 |
| `货品标题` | string | 货品名称 |
| `单价(元)` | float | 单品价格 |
| `数量` | float | 购买数量 |
| `单位` | string | 数量单位 |
| `Offer ID` | string | 1688商品 ID |
| `SKU ID` | string | SKU ID |

### 订单状态枚举

| 状态值 | 说明 | 是否纳入统计 |
|--------|------|-------------|
| `交易成功` | 成功完成 | ✅ 是 |
| `交易关闭` | 交易关闭（含退款关闭） | ✅ 是 |
| `等待买家确认收货` | 已发货待确认 | ✅ 是 |
| `等待买家付款` | **待付款** | ❌ **排除** |
| `退款中` | 退款处理中 | ✅ 是 |
| `等待卖家发货` | 已付款待发货 | ✅ 是 |
| `已发货` | 已发货 | ✅ 是 |

## Clarified Decisions

| 决策项 | 结论 |
|--------|------|
| 文件格式 | 仅支持 `.xlsx`（1688 标准导出格式）；不支持 `.csv` |
| 解析行策略 | 仅解析**主订单行**（`订单编号` 非空的行）；续行（多货品订单的追加货品行）忽略不导入 |
| 统计排除规则 | 统计时**排除** `订单状态 = '等待买家付款'` 的订单 |
| 聚合维度 | 以 `卖家公司名` 为唯一聚合键 |
| 月份筛选 | 基于 `订单创建时间` 字段按年月筛选；默认展示**当前月份** |
| 统计指标 | 每家供应商展示：订单数（count）、实付款合计（sum of 实付款(元)）、该月采购次数最多的货品标题（`top_goods`） |
| 去重策略 | 以 `订单编号` 为唯一键，重复导入时更新已有记录（upsert） |
| 导入入口 | 新建独立导入入口，不复用现有淘宝订单导入页面 |
| 导入格式校验 | 文件必须包含 `订单编号`、`卖家公司名`、`实付款(元)`、`订单状态`、`订单创建时间` 列；缺失时返回 422 |
| 无效行处理 | 主订单行中 `实付款(元)` 为空或无法解析的行跳过，计入 `errors`，不中断导入 |
| 空卖家公司名 | 主订单行 `卖家公司名` 为空时，以字符串 `'未知供应商'` 作为 `seller_name` 导入，不跳过 |
| 文件大小限制 | 上传文件超过 **10 MB** 时，后端返回 413，前端提示「文件过大，请检查」 |
| 月份选择器范围 | 下拉列表展示数据库中实际存在的所有年月（动态生成，无硬编码） |
| 供应商详情交互 | 点击供应商行**在同一页面内联展开**订单明细列表，无需跳转新页面 |
| 订单明细字段 | 明细展示：订单编号、货品标题（截断至 40 字）、实付款、订单状态、订单创建时间 |
| 数据留存 | 无上限，全量保留所有导入历史 |
| 时区 | 使用文件原始时间存储，不做时区转换（默认 CST） |

## Data Model

### PurchaseOrder（1688采购订单）

新建 `PurchaseOrder` 表，与现有 `Order`、`SubOrder` 等表**并存**，不影响已有功能。

```
PurchaseOrder
  id            : int (PK, autoincrement)
  order_id      : str (unique, index, 订单编号)
  seller_name   : str (index, 卖家公司名；空值替换为 '未知供应商')
  seller_member : Optional[str] (卖家会员名)
  goods_title   : Optional[str] (货品标题，主订单行的第一个货品名，max_length=500)
  goods_total   : Optional[float] (货品总价(元))
  shipping_fee  : Optional[float] (运费(元))
  discount      : Optional[float] (涨价或折扣(元))
  paid_amount   : float (实付款(元))
  status        : str (订单状态)
  created_at    : Optional[datetime] (订单创建时间)
  paid_at       : Optional[datetime] (订单付款时间)
  imported_at   : datetime (导入时间, default=now)
```

## User Scenarios & Testing

### User Story 1 - 导入 1688 采购订单文件 (Priority: P1)

作为店主，我可以上传 1688 导出的采购订单 xlsx 文件，将订单数据导入系统，作为供应商统计分析的数据基础。

**Why this priority**: 没有采购数据，供应商统计无法运行，是所有后续功能的前提。

**Independent Test**: 上传 `1688.xlsx`（2238 行，1778 条主订单），等待导入完成，确认页面显示「导入 1778 条，更新 0 条，跳过 0 条」。

**Acceptance Scenarios**:

1. **Given** 我在导入页面，**When** 我上传符合格式的 1688 xlsx 文件并点击"导入"，**Then** 系统解析主订单行并写入数据库，返回 `{imported, updated, errors}`。
2. **Given** 我重新上传包含相同订单编号的文件，**When** 导入完成，**Then** 重复订单被更新（upsert），`updated` 计数增加，`imported` 为新增数量。
3. **Given** 上传的文件缺少 `卖家公司名` 列，**When** 我点击导入，**Then** 系统返回 422 错误，提示缺失的列名。
4. **Given** 文件含有 `实付款(元)` 为空的主订单行（异常数据），**When** 导入时，**Then** 该行跳过并计入 `errors`，其余行正常导入。

---

### User Story 2 - 按月查看供应商采购汇总 (Priority: P1)

作为店主，我可以在供应商管理页面选择月份，查看当月各供应商的订单数量与实付款合计，以便了解本月采购结构和供应商依赖情况。

**Why this priority**: 这是核心分析视图，也是本功能的主要使用场景。

**Independent Test**: 选择 2026 年 3 月，确认页面展示 71 家供应商中在 3 月有订单的供应商列表，并验证「万道珠宝首饰厂」的订单数和金额与手工计算结果一致（排除待付款订单后）。

**Acceptance Scenarios**:

1. **Given** 已导入订单，**When** 我打开供应商管理页面，**Then** 默认显示当前月份的供应商汇总表，包含：供应商名称、订单数、实付款合计，按实付款合计降序排列。
2. **Given** 汇总页面已加载，**When** 我从月份下拉框选择 2026-03，**Then** 表格立即更新为该月数据，排除了所有「等待买家付款」状态的订单。
3. **Given** 汇总页面已加载，**When** 当月没有采购数据，**Then** 页面显示「暂无数据」提示，不显示空表格。
4. **Given** 汇总页面显示供应商列表，**When** 我点击供应商行，**Then** 该行下方**内联展开**订单明细列表，无需跳转新页面；再次点击折叠。

---

### User Story 3 - 查看单个供应商订单明细 (Priority: P2)

作为店主，我可以点击供应商名称，查看该供应商在选定月份内的所有订单明细，包括每单的货品标题、实付款和订单状态。

**Why this priority**: 明细视图用于核对账目和追溯具体采购，是汇总的支撑视图。

**Independent Test**: 选择 2026-03，点击「万道珠宝首饰厂」，确认展示该月该供应商所有订单，订单数与汇总表一致，且无「等待买家付款」订单。

**Acceptance Scenarios**:

1. **Given** 我在汇总页面选择了月份并点击了供应商行，**When** 明细列表展开，**Then** 该行下方显示该供应商在该月的所有订单（排除待付款），每条记录包含：订单编号、货品标题（截断至 40 字）、实付款（元）、订单状态、订单创建时间。
2. **Given** 明细列表已展开，**When** 我再次点击同一供应商行，**Then** 明细列表折叠，恢复到汇总视图。
3. **Given** 供应商在选定月份内仅有「等待买家付款」订单，**When** 点击该供应商行，**Then** 展开区域显示「暂无有效订单」提示。

## Functional Requirements

| ID | 要求 | 优先级 |
|----|------|--------|
| FR-001 | 系统提供 1688.xlsx 导入入口，支持文件上传 | P1 |
| FR-002 | 导入时仅解析主订单行（`订单编号` 非空），续行忽略 | P1 |
| FR-003 | 以 `订单编号` 为幂等键执行 upsert，避免重复插入 | P1 |
| FR-004 | 导入缺失必要列时返回 422 并说明缺失列名 | P1 |
| FR-005 | 供应商汇总 API 支持按年月（`year` + `month` 参数）筛选 | P1 |
| FR-006 | 供应商汇总统计时排除 `订单状态 = '等待买家付款'` 的订单 | P1 |
| FR-007 | 汇总结果包含：`seller_name`、`order_count`、`total_paid`、`top_goods`（该月出现次数最多的 `goods_title`） | P1 |
| FR-008 | 汇总结果按 `total_paid` 降序排列 | P1 |
| FR-009 | 月份下拉选项动态生成，来自数据库实际月份 | P1 |
| FR-010 | 供应商订单明细 API 支持按 `seller_name` 和年月筛选 | P2 |
| FR-011 | 明细列表分页，每页 20 条，支持页码切换 | P2 |
| FR-012 | 前端导航栏新增「供应商管理」入口 | P1 |

## Non-Functional Requirements

| ID | 要求 |
|----|------|

## API Contract (Draft)

### POST /api/purchase-orders/import

导入 1688 采购订单 xlsx 文件。

**Request**: `multipart/form-data`，字段 `file`（`.xlsx`）

**Response 200**:
```json
{
  "imported": 1767,
  "updated": 0,
  "errors": 0
}
```

**Response 413**: 文件超过 10 MB
```json
{ "detail": "文件过大，请检查" }
```

**Response 422**: 文件缺少必要列
```json
{
  "detail": "缺少必要列: 卖家公司名, 实付款(元)"
}
```

---

### GET /api/purchase-orders/suppliers?year=2026&month=3

按月返回供应商采购汇总（已排除待付款订单）。

**Query Parameters**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `year` | int | 是 | 年份，如 `2026` |
| `month` | int | 是 | 月份，`1`-`12` |

**Response 200**:
```json
{
  "year": 2026,
  "month": 3,
  "suppliers": [
    {
      "seller_name": "海丰县城东镇万道珠宝首饰厂",
      "order_count": 198,
      "total_paid": 1452.80,
      "top_goods": "镀金文玩黄金弟子珠金刚杵吊坠头菩提佛珠..."
    }
  ]
}
```

---

### GET /api/purchase-orders/months

返回数据库中实际存在订单的所有年月列表，供前端月份下拉框使用。

**Response 200**:
```json
{
  "months": [
    { "year": 2026, "month": 2 },
    { "year": 2026, "month": 3 },
    { "year": 2026, "month": 4 },
    { "year": 2026, "month": 5 }
  ]
}
```

---

### GET /api/purchase-orders?seller_name=X&year=2026&month=3&page=1&page_size=20

查询指定供应商在指定月份的订单明细（已排除待付款订单）。

**Query Parameters**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `seller_name` | string | 是 | 供应商公司名 |
| `year` | int | 是 | 年份 |
| `month` | int | 是 | 月份 |
| `page` | int | 否 | 页码，默认 1 |
| `page_size` | int | 否 | 每页条数，默认 20，最大 100 |

**Response 200**:
```json
{
  "seller_name": "海丰县城东镇万道珠宝首饰厂",
  "year": 2026,
  "month": 3,
  "total": 198,
  "page": 1,
  "page_size": 20,
  "orders": [
    {
      "order_id": "5117588929711087621",
      "goods_title": "镀金文玩黄金弟子珠金刚杵吊坠头菩提佛珠...",
      "paid_amount": 38.10,
      "status": "等待买家确认收货",
      "created_at": "2026-05-26T13:55:41"
    }
  ]
}
```
